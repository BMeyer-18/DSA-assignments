# DSA-assignments
A repository for assignments (3 and on) from Olin College's Data Structures and Algorithms course. Notes about individual assignments written below:

## Assignment 3
The graph implementation is in the Graph class, the priority queue implementation is in the MinPriorityQueue class, and my min heap implementation (which I wrote myself) is in the MinHeap class. There are also Test files for all three classes containing unit tests, which are run in the Main file.  

The graph traversal methods are all in the Graph class, towards the end. I used the Graph class for the BFS and DFS implementations we did in-class during class 6, so those are in there too, right above my Dijkstra implementation. The unit tests for all 3 are based on the Class 7 presentation. I applied the Dijkstra algorithm to the Project Euler problem linked in the assignment, which is in two functions in the ProjectEulerProblem file. Once again, everything is run in Main.
